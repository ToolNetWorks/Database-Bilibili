# Database-Bilibili

Independent Bilibili metadata and channel management backend.

## Features

- Bilibili channel discovery
- Video metadata extraction
- BVID and URL normalization
- FREE / POWER / POWER_PREVIEW classification
- Premium session integration
- REST API (in development)

## Technology

- Python
- yt-dlp
- FastAPI (planned)
- Neon PostgreSQL (planned)

## Security

Bilibili session cookies, credentials, environment files
and downloaded media must never be committed to GitHub.

## Project status

Initial development.
